- **Title**: GreenWave 3D (Edit 01)
- **Timestamp**: `2026-10-29T15:58:33+05:30`
- **Scope**: Initial production build of GreenWave 3D.

## Deliverables & Architecture
1. **Frontend & 3D Stack**: React 19 (Vite), Tailwind CSS v4, Lucide React, Three.js (r186), `@react-three/fiber` (v9.8), `@react-three/drei` (v10.7).
2. **Zero-Auth Instant Entry**: Directly opens into the 3D War Room with no login walls.
3. **Dual-Mode SDK Resilience**: Automatic fallback between live API keys (`VITE_GEMINI_API_KEY`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) and deterministic simulated AI triage + LocalStorage ledger.
4. **3-Tab Navigation**:
   - **Tab 1: 3D City War Room**: 7×7 grid, 49 signalized intersections, 165 moving vehicles, emergency ambulance AMB-07, 3-junction pre-flush green wave.
   - **Tab 2: Emergency Triage & Gemini Dispatch**: 3 photorealistic sample scenarios, strict JSON prompt engine, time-saved calculation.
   - **Tab 3: Command Analytics & Supabase Log**: 18.5m standard GPS vs 6.2m GreenWave benchmark chart, live corridor audit table, CSV export.
5. **Config & Database**:
   - `.env.example`
   - `supabase_setup.sql` with RLS disabled for hackathon testing.
